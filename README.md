Security Operations Center (SOC) analysts are overwhelmed by the sheer volume of alerts they receive daily. On average, they handle thousands of alerts, but nearly 70% of them are false positives. Despite this, every alert must be investigated. The process is painfully manual—analysts read through alert texts, copy-paste IP addresses, domain names, or file hashes into platforms like VirusTotal, AlienVault OTX, and AbuseIPDB, wait for responses, and then manually correlate results across these different sources. This cycle repeats for every single IOC, taking anywhere from 10 to 15 minutes per check. With hundreds of alerts flooding in every day, this approach is not only inefficient but also exhausting. Analysts burn out, real threats get missed, and response times lag dangerously behind what modern cyberattacks demand. This project is designed to break that cycle.
The primary objective is to build ThreatSense AI — an automated IOC Threat Intel Checker that handles the entire investigation pipeline from start to finish without any human intervention. The tool takes raw alert text, extracts Indicators of Compromise using Regular Expressions, applies a 3-layer filtering system to remove irrelevant noise, enriches the remaining IOCs by querying three threat intelligence APIs in parallel, assigns a dynamic risk score, generates a human-readable summary using a local AI model, and saves everything as a structured JSON report. All of this happens in less than five seconds. The measurable goals are clear: reduce investigation time from 15 minutes to under 5 seconds, bring false positives down from 70% to under 10%, and achieve full automation of the IOC investigation workflow.
On a technical level, the tool integrates VirusTotal for malicious vendor detection, AlienVault OTX for community threat intelligence, and AbuseIPDB for IP reputation scoring—all queried simultaneously to minimize latency. The 3-layer filtering discards private IPs, known safe domains, and flags suspicious domains using Shannon entropy analysis, TLD checks, and brand impersonation detection. The risk scoring system is weighted and dynamic, adjusting based on multiple factors including vendor flags, threat pulses, and domain characteristics. For summarization, the tool uses Ollama with TinyLlama, a lightweight language model that runs locally, ensuring no sensitive data leaves the environment and no API cost incurred.
